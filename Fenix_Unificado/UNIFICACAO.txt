FENIXTRAINING — PROJETO UNIFICADO

Estrutura principal:
- HTML das páginas na raiz da pasta Fenix
- EstiloFENIX/: arquivos CSS
- Scripts/: JavaScript existente
- FIREImgs/: imagens
- Banco/: scripts SQL do Supabase

A versão Fenix.zip foi usada como base para os arquivos que já existiam nela.
Foram incorporados do Fenix-main.zip os arquivos exclusivos:
- Quest.html
- Quest2.html (reposicionado da pasta EstiloFENIX para a raiz)
- EstiloFENIX/Quest.css
- LEIA-ME.txt

A referência a Quest2.css foi removida de Quest2.html porque esse arquivo não existe
em nenhum dos dois ZIPs recebidos. Os dois questionários fazem referência a
Scripts/quest.js, mas esse arquivo também não foi fornecido. Portanto, a lógica
JavaScript dos questionários ainda precisa ser integrada/criada.

O projeto mantém a pasta raiz Fenix, adequada para abrir no VS Code e configurar
como diretório raiz do projeto na Vercel.
